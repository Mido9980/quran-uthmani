# المصحف الشريف — تطبيق ويب/PWA

مصحف المدينة النبوية كامل (604 صفحة، رسم عثماني، رواية حفص) كتطبيق ويب يعمل على كل الأجهزة وبدون إنترنت.

## المميزات
1. 604 صفحة بجودة عالية (صور PNG ثنائية اللون، حجم إجمالي ~35 ميجا)
2. فهرس 114 سورة + 30 جزء + بحث
3. العلامات المرجعية وحفظ آخر صفحة
4. خمسة ألوان للصفحة: ورقي، أبيض، سيبيا، أخضر، ليلي
5. تنقل بالسحب واللمس وأزرار الكيبورد
6. تحميل المصحف كامل للقراءة أوفلاين
7. PWA: يثبت كتطبيق على أندرويد وiOS وويندوز وماك ولينكس

## المصدر
صفحات المصحف من إصدار مجمع الملك فهد لطباعة المصحف الشريف بالمدينة المنورة (عبر pdfquran.com).
لا يوجد اعتماد موثق من لجنة مراجعة المصحف بالأزهر لهذا الملف؛ للنشر الواسع يجب الحصول على إذن رسمي.

## التشغيل
python3 -m http.server 8080 ثم افتح http://localhost:8080
